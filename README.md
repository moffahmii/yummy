# Food Recipes App
A responsive and dynamic web application for browsing meals, categories, areas, and ingredients using TheMealDB API.  
The project includes smooth animations, an interactive side navigation menu, and a modern UI/UX design.

---

## Features

- Search meals by name or first letter  
- Browse categories  
- Browse meals by area  
- Browse by ingredients  
- Detailed meal page with instructions and tags  
- Animated side navigation menu  
- Loading screen animation  
- Fully responsive design

---

## Technologies Used

| Technology | Usage |
|-----------|--------|
| HTML5 | Structure and layout |
| CSS3 | Styling and animations |
| Bootstrap 5 | Grid system and utility classes |
| Font Awesome | Icons |
| Vanilla JavaScript (ES6) | Logic, API handling, interactivity |
| TheMealDB API | Data source for meals |
| Custom Loader Animation | Smooth UX loading screen |
